## About

This repo began as a home for coursework from the **M.S. in Applied Artificial Intelligence (University of San Diego)**. Projects now live in dedicated repos, linked below. Older work remains on this repo's [branches](#archived-project-branches).

## Featured projects

### Machine learning & MLOps
| Project | What it is |
|---|---|
| [mlops-cardiovascular-pipeline](https://github.com/oxayavongsa/mlops-cardiovascular-pipeline) | "Aorta Guard" (AAI-540 MLOps): a cardiovascular-disease detection pipeline with a feature store, batch inference, CI/CD and SageMaker + CloudWatch monitoring. |
| [mental-health-risk-modeling](https://github.com/oxayavongsa/mental-health-risk-modeling) | Three-class risk predictor comparing logistic regression, a TabNet-style neural network and a soft-voting ensemble, with a Gradio UI. |
| [ml-vehicle-fraud-detection](https://github.com/oxayavongsa/ml-vehicle-fraud-detection) | Vehicle-insurance claim fraud detection on 15,420 claims, using SMOTE, Isolation Forest, XGBoost, CatBoost and other tuned classifiers. |
| [real-estate-tier-classification](https://github.com/oxayavongsa/real-estate-tier-classification) | AAI-501 project that classifies U.S. listings into pricing tiers with multiple classification algorithms. |
| [end-to-end-statistical-analysis](https://github.com/Aaron-m-ram/end-to-end-statistical-analysis) | Team project (hosted by a teammate): end-to-end statistical analysis in Jupyter. |

### Deep learning, NLP & computer vision
| Project | What it is |
|---|---|
| [nlp-context-aware-chatbot](https://github.com/oxayavongsa/nlp-context-aware-chatbot) | AAI-520 NLP: a multi-turn T5 chatbot trained on the Cornell Movie-Dialogs Corpus. |

### IoT & time series
| Project | What it is |
|---|---|
| [iot-smarthouse-energy](https://github.com/oxayavongsa/iot-smarthouse-energy) | AAI-530 final project forecasting smart-home conditions with LSTM, CNN and SARIMAX, plus a Tableau dashboard. |
| [aai-iot-cleaning-and-eda](https://github.com/oxayavongsa/aai-iot-cleaning-and-eda) | Course lab: cleaning and EDA of 2M+ minute-level household power readings. |
| [aai-iot-linear-regression](https://github.com/oxayavongsa/aai-iot-linear-regression) | Course lab: streaming weighted linear regression with a forgetting factor for 5-minute-ahead power forecasts. |
| [aai-iot-lstm](https://github.com/oxayavongsa/aai-iot-lstm) | Course lab: stacked-LSTM power forecasting, benchmarked against the regression baseline. |
